Accent is iris (blue-violet) and is the only decorative hue. Status colours carry meaning only: success, warning, danger, info. Agent states map onto them: running = accent, needs-you = warning, done = success, failed = danger. Neutrals are tinted toward the accent so greys read as chosen.
